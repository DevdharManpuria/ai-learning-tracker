## 🤝 Collaboration Guidelines

1. **Keep to Your Folder:** Write all daily/weekly notes and scripts inside your personal folder to avoid Git merge conflicts.
2. **Document Key Takeaways:** When finishing a concept, include a short markdown summary of tricky intuition or gotchas.
3. **Cross-Pollinate:** Drop valuable research papers, articles, or useful repositories into `shared/resources.md`.
